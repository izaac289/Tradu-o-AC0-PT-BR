# Tradução-AC0-PT-BR
uma tradução para Ace combat 0

fiz essa tradução para uso pessoal primeiramente mas ai decidi liberar para caso alguém quiser usar e ja ir mostrando alguns erros alem 
Usei o claude para extrair os textos, passei para o Ollama fazer uma tradução bruta e novamente o claude Opus para uma revisão comparando com os textos originas. 
O QUE ESTÁ TRADUZIDO
- Todas as falas de rádio das missões (com o nome de quem fala)
- Briefings e relatórios pós-missão
- Cenas do documentário, entrevistas e apresentações dos esquadrões de ases

O QUE NÃO ESTÁ TRADUZIDO (por enquanto)
- Menus, textos de ajuda e títulos de missão (são imagens)
- A citação da abertura (está gravada no vídeo)
- Jargões de rádio como "Fox Two" e nomes próprios foram mantidos de propósito

COMO INSTALAR
1. Copie TODOS os arquivos deste pacote para a pasta ACZero do jogo
   (a mesma pasta onde fica o arquivo d.arc). Exemplo:
   ...\steamapps\common\ACE COMBAT ZERO THE BELKAN WAR (Steam Version)\ACZero
2. Dê dois cliques em 1_INSTALAR_TRADUCAO.bat
3. No jogo, ao iniciar a campanha, escolha as legendas em ENGLISH (US).

COMO REMOVER
- Dê dois cliques em 2_REMOVER_TRADUCAO.bat, ou use
  Steam > Propriedades > Arquivos instalados > Verificar integridade.
